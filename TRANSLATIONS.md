# Translations

The English [README](README.md) is the authoritative source. Translated READMEs are
overviews; when they disagree with English, English wins.

These translations are currently AI-assisted and have not been reviewed by native
speakers. Corrections and native review are welcome.

The application UI uses the same eight languages but has its own catalogs under
[`src/shared/i18n/catalogs`](src/shared/i18n/catalogs); see
[`src/shared/i18n/README.md`](src/shared/i18n/README.md) for its scope, status
and contribution rules. Application translations are also AI-assisted and marked
for native review.

## Maintenance

- Update translations at release boundaries, not on every English commit.
- Keep product names, code blocks, commands, URLs, screenshots, and badges unchanged.
- Translate headings, alt text, and status copy.
- Do not add a language without a reviewer willing to keep it current.
- Record the last synced English commit when refreshing a translation.
